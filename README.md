# User Information Dashboard

A responsive user dashboard that captures and manages user profile data. The webpage stores user information locally in the browser and provides a dynamic and personalized experience.


---

##  Overview

User Information Dashboard is a front-end web application that allows users to input their personal information and instantly receive a dynamic profile summary. The system persists data using browser storage, ensuring the user experience is maintained across page reloads.

This project demonstrates practical implementation of:

- Form handling
- Local storage
- Conditional rendering
- JavaScript functions

---

##  Features

-  User data capture (Name & Age)
- Persistent storage using `localStorage`
-  Auto-load user data on refresh
- Personalized greeting
- Age verification status 
- Age conversion to months
- Motivational message 
- Reset functionality 
- Responsive and clean UI design

---

## How It Works

1. User submits name and age through a form
2. Data is stored in browser localStorage
3. Dashboard updates instantly with computed values:
   - Greeting message
   - Age status validation
   - Age in months calculation
   - Motivational quotes
4. On page reload, data is automatically restored
5. Reset button clears the displayed dashboard view
